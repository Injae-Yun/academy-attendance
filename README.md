# 음악학원 출결 관리 시스템

기존 **「학원관리시스템」** 스프레드시트에 얹는 Google Apps Script 웹앱입니다.
태블릿으로 학생을 눌러 등·하원 시각을 남기고, 보호자에게 카카오 알림톡을 보내며,
출석부는 명단에서 자동으로 생성·기입됩니다.

> **가장 중요한 제약**
> 기존 11개 시트의 **구조(열 추가/삭제/이동)는 절대 변경하지 않습니다.**
> 대시보드·수강료(월별)·수입/지출이 전부 QUERY/SUMIFS로 명단을 참조하기 때문입니다.
> 앱은 `_출결_*` 시트를 새로 만들고, 기존 시트에는 정해진 칸만 씁니다.

---

> **이 저장소에는 실제 학생 정보를 올리지 않습니다.**
> 문서와 주석의 이름(홍길동·김철수·이영희 등)은 전부 예시이며 실존 인물이 아닙니다.
> 스크립트 ID·연락처·학원명도 자리표시자입니다.
> 실데이터는 스프레드시트에만 두고, 커밋 전 `git diff` 로 한 번 확인해주세요.

# 설치 절차

처음부터 순서대로 따라가시면 됩니다. **0단계를 건너뛰지 마세요.**

## 0단계 — 사본을 먼저 만드세요

2년치 실데이터가 든 원본에 검증 안 된 쓰기를 하지 않습니다.

1. 스프레드시트를 엽니다
2. **파일 → 사본 만들기**
3. 이름을 `학원관리시스템 (테스트)` 정도로 두고 만듭니다
4. **아래 모든 단계는 이 사본에서 진행합니다.** 잘 돌아가는 걸 확인한 뒤 원본에 배포합니다

## 1단계 — Apps Script 프로젝트 만들기

**사본 스프레드시트에서** 진행합니다.

1. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭
2. 새 탭에 편집기가 열립니다 (빈 프로젝트가 자동 생성됩니다)

> ⚠️ 반드시 **스프레드시트 메뉴에서** 만드세요.
> script.google.com 에서 직접 새로 만들면 시트에 붙지 않는 독립 프로젝트가 되어
> `SpreadsheetApp.getActive()` 가 동작하지 않습니다.

## 2단계 — 스크립트 ID 복사하기

Apps Script 편집기에서:

1. 왼쪽 사이드바 맨 아래 **⚙️ 프로젝트 설정** 클릭
2. **스크립트 ID** 항목의 **복사** 버튼 클릭

주소창에서 직접 읽어도 됩니다. 가운데 긴 문자열이 ID입니다.

```
https://script.google.com/home/projects/1AbCdEfGhIjKlMnOpQrStUvWxYz0123456789abcdefghijklmno/edit
                                        └────────────────── 이 부분이 스크립트 ID ──────────────────┘
```

영문·숫자·`_`·`-` 로 이루어진 **57자 안팎**의 문자열입니다.

## 3단계 — `.clasp.json` 에 ID 적기

**ID는 파일 이름이 아니라 파일 *안에* 들어갑니다.**

프로젝트 폴더의 `.clasp.json` 을 메모장이나 편집기로 열면 이렇게 되어 있습니다.

```json
{
  "scriptId": "여기에_Apps_Script_프로젝트_ID를_넣으세요",
  "rootDir": "src"
}
```

큰따옴표 **안의 문구만** 지우고 2단계에서 복사한 ID를 붙여넣습니다.
`rootDir` 은 건드리지 않습니다.

```json
{
  "scriptId": "1AbCdEfGhIjKlMnOpQrStUvWxYz0123456789abcdefghijklmno",
  "rootDir": "src"
}
```

> `.clasp.json` 이 없다면 `.clasp.json.example` 을 복사해 만듭니다.
> `cp .clasp.json.example .clasp.json` — 이건 **파일을 복사하는 명령**일 뿐이고,
> ID는 그다음에 파일을 열어서 넣습니다.

## 4단계 — Apps Script API 켜기

한 번만 하면 됩니다. 꺼져 있으면 `User has not enabled the Apps Script API` 오류가 납니다.

1. https://script.google.com/home/usersettings 접속
2. **Google Apps Script API** 를 **사용** 으로 전환

## 5단계 — 업로드

프로젝트 폴더에서 터미널을 열고:

```bash
npm install          # 최초 1회
npx clasp login      # 브라우저가 열리면 학원 구글 계정으로 로그인
npx clasp push       # 소스 업로드
```

`Pushed 10 files.` 같은 메시지가 나오면 성공입니다.
Apps Script 편집기를 새로고침하면 `Config.gs`, `Sync.gs` … 파일들이 보입니다.

## 6단계 — 최초 설치 실행

**스프레드시트 탭으로 돌아가 새로고침(F5)** 합니다.
상단에 **[출결 관리]** 메뉴가 생깁니다. (안 보이면 30초쯤 기다렸다 다시 새로고침)

순서대로 실행합니다.

1. **출결 관리 → 설치·설정 → 최초 설치**
   - 처음 실행하면 권한 승인 창이 뜹니다. **고급 → (프로젝트명)(으)로 이동 → 허용**
   - `_출결_*` 시트가 만들어지고 기존 시트 좌표를 실측합니다
   - 리포트에 `[확인 필요]` 항목이 없어야 정상입니다

2. **관리자 PIN 설정** — Apps Script 편집기에서
   - 상단 함수 선택 목록에서 `setAdminPin` 선택
   - 코드에서 `setAdminPin('1234')` 처럼 원하는 PIN 을 넣어 잠시 바꾼 뒤 ▶ 실행
   - 평문이 아니라 해시로 저장됩니다. 실행 후 코드를 원래대로 돌려놓으세요

3. **출결 관리 → 명부 동기화**
   - 명단 3종을 읽어 학생 마스터를 만듭니다
   - 재원 68명 · 휴원 1명 · 퇴소 85명이 나오면 정상입니다

4. **출결 관리 → 지출 관리 → 원장 점검** → **원장 정리 미리보기** → 내용 확인 후 **원장 정리 실행**

5. **출결 관리 → 출석부 재생성**
   - 확인 창에서 확인을 누르면 현재 연/월 출석부를 명단에서 다시 그립니다
   - 기록된 O 는 `출석부(DB)` 원장에서 그대로 복원됩니다

## 7단계 — 웹앱 배포 (앱을 쓰려면 필요합니다)

`최초 설치` 만으로는 태블릿 화면이 열리지 않습니다. 웹앱으로 배포해야 주소가 생깁니다.

1. Apps Script 편집기 우측 상단 **배포 → 새 배포**
2. 톱니바퀴 ⚙️ → **웹 앱** 선택
3. 설정
   - **설명**: 아무거나 (예: `출결 v1`)
   - **다음 사용자 인증 정보로 실행**: **나**
   - **액세스 권한이 있는 사용자**: **모든 사용자**
4. **배포** → 권한 승인 (고급 → 이동 → 허용)
5. 나온 **웹 앱 URL** 을 복사
6. 스프레드시트로 돌아와 **[출결 관리] → 웹앱 주소 등록** 에 붙여넣기

> "모든 사용자" 로 열어야 태블릿에서 구글 로그인 없이 쓸 수 있습니다.
> 대신 앱이 자체적으로 **관리자 PIN + 기기 토큰**으로 접근을 막습니다.
> 주소를 아는 것만으로는 명부가 보이지 않습니다.

### 6번을 건너뛰면 메뉴의 주소가 열리지 않습니다

주소를 등록해두지 않으면 **[출결 앱 열기]** 가 `/exec` 가 아니라 `/dev` 로 끝나는
**개발용 주소**를 안내합니다. `/dev` 는 스크립트 편집 권한이 있는 계정에서만 열려서
태블릿에서는 열리지 않고, 구글 계정이 여러 개 로그인돼 있으면 본인 PC 에서도 열리지 않습니다.

```
https://script.google.com/macros/s/.../exec   ← 이걸 등록하세요
https://script.google.com/macros/s/.../dev    ← 편집자 전용. 태블릿에서 안 열립니다
```

등록해두면 메뉴가 두 주소를 알려줍니다.

| 메뉴 | 주소 |
|---|---|
| 출결 앱 열기 | `…/exec` |
| 관리자 화면 열기 | `…/exec?page=admin` |

주소 창에는 **복사 버튼**이 있습니다. 모달 안의 링크는 팝업 차단에 걸리는 일이 있어
복사해서 주소창에 붙여넣는 편이 확실합니다.

> **"새 배포" 로 다시 배포하면 주소가 바뀝니다.** 그때는 [웹앱 주소 등록] 을 다시 해주세요.
> "배포 관리 → 연필 → 새 버전" 으로 올리면 주소는 그대로라 다시 등록할 필요가 없습니다.

### 태블릿에서 첫 실행

**기기 등록 화면은 평소에 뜨지 않습니다.** 등록할 때만 시한부 링크를 만듭니다.

1. 스프레드시트 메뉴 **[출결 관리] → 기기 등록 링크** — 30분짜리 주소가 나옵니다
2. 그 주소를 태블릿 브라우저로 엽니다 — 여기서만 **기기 등록** 화면이 뜹니다
3. 관리자 PIN, 기기 별명, 모드를 입력합니다
   - 현관에 두고 학생이 직접 누르면 **키오스크**
   - 데스크에서 선생님이 누르면 **직원**
4. 등록되면 명부가 뜹니다. 토큰이 브라우저에 저장되어 다음부터는 바로 열립니다
5. 화면에 나오는 **즐겨찾기 주소**(`?t=토큰`)를 저장하세요. 그 뒤로는 등록 링크가 필요 없습니다
6. 브라우저 메뉴에서 **홈 화면에 추가** 하면 전체화면 앱처럼 쓸 수 있습니다

> 등록 링크 없이 웹 앱 주소를 열면 **"등록된 기기가 아닙니다"** 만 나옵니다.
> PIN 입력창조차 보이지 않습니다.

### 코드를 고친 뒤 반영하는 법 — 링크는 바뀌지 않습니다

`clasp push` 만으로는 태블릿에 반영되지 않습니다. 배포 버전을 올려야 합니다.

```
배포 → 배포 관리 → (기존 배포의) 연필 ✏️ → 버전: 새 버전 → 배포
```

| 방법 | 링크 |
|---|---|
| **배포 관리 → 연필 → 새 버전** | **그대로 유지** ✅ |
| **새 배포** 를 다시 만들기 | **새 링크 발급** ❌ |

**"새 배포" 는 처음 한 번만** 하시고, 이후에는 항상 연필로 버전만 올리세요.
그러면 태블릿의 즐겨찾기도 기기 등록도 건드릴 필요가 없습니다.

> 실수로 새 배포를 만들었다면 이전 배포도 계속 살아 있으므로 예전 링크가 그대로 동작합니다.
> 다만 두 버전이 동시에 도는 상태가 되니, 쓰지 않는 배포는 **배포 관리 → 보관처리** 해주세요.

### 즐겨찾기 주소에 기기 토큰이 들어갑니다

기기 등록을 마치면 **주소를 안내하는 화면**이 뜹니다. 이 주소를 홈 화면에 추가해주세요.

```
https://script.google.com/macros/s/.../exec?t=<기기토큰>
```

Apps Script 는 화면을 `googleusercontent.com` 의 임의 하위 도메인 iframe 으로 띄우는데
**이 도메인이 바뀔 수 있습니다.** 그러면 브라우저에 저장된 기기 토큰이 사라져
현관에서 갑자기 관리자 PIN 을 다시 묻게 됩니다.
주소에 토큰을 실어두면 그런 상황에서도 즐겨찾기만으로 복구됩니다.

> 이 주소를 아는 사람은 그 기기와 같은 권한을 갖습니다. 태블릿 밖으로 공유하지 마세요.
> 유출되었다면 `_출결_기기` 시트에서 해당 행의 **활성** 을 `FALSE` 로 바꾸면 즉시 차단됩니다.

## 8단계 — 검증

Apps Script 편집기에서 함수 `testAll` 을 선택하고 ▶ 실행한 뒤
**실행 로그**(Ctrl+Enter)를 확인합니다. `실패 0` 이면 정상입니다.

스프레드시트에서도 눈으로 확인하세요.

- 출석부에 `김철수` 가 2행(피아노/작곡)으로 나오고 이름 뒤 `P`/`C` 가 없는지
- 기존에 찍혀 있던 O 가 그대로인지 (2026년 8월 기준 **55칸**)
- 대시보드의 매출액·재적 인원이 **설치 전과 동일한지** ← 기존 수식 무손상 확인

## 9단계 — 자동 실행 켜기

**출결 관리 → 설치·설정 → 자동 실행 켜기** 를 누르면 아래가 돌기 시작합니다.

| 주기 | 하는 일 |
|---|---|
| 1분마다 | 발송 대기 건 처리 |
| 매일 04시 | 명부 동기화 (신규·퇴소 자동 반영) |
| 매월 1일 05시 | 새 달 출석부 생성 |
| 시트 편집 시 | 출석부 연/월을 바꾸면 그 달로 다시 그림 |

`자동 실행 상태` 로 확인하고, `자동 실행 끄기` 로 전부 해제할 수 있습니다.

## 10단계 — 원본에 배포

### 사본과 원본을 오가는 법

`clasp` 은 `.clasp.json` **하나만** 읽습니다. 두 프로젝트를 오갈 때마다 `scriptId` 를
손으로 고치면 언젠가 반대쪽에 push 하는 사고가 납니다. 전환 도구를 써주세요.

```bash
# 최초 1회 — 두 프로젝트의 스크립트 ID 를 이름으로 등록
node scripts/target.js set 사본 1cyr...O3I
node scripts/target.js set 원본 <원본 스크립트 ID>

# 이후에는 한 줄로 전환
npm run use 원본
npm run use 사본

npm run targets    # 등록된 대상 목록 (● 가 현재)
npm run which      # 지금 어느 쪽인지
```

`npm run push` 는 **push 전에 항상 현재 대상을 찍어줍니다.**
원본으로 전환하면 빨간 경고가 뜹니다.

```
  전환 완료 → 원본 (원본)
  ⚠ 원본입니다. push 하면 실제 학원 데이터에 반영됩니다.
```

> `.clasp.targets.json` 은 `.gitignore` 에 있어 커밋되지 않습니다.

8단계가 전부 통과하면 원본 스프레드시트에서 1~7단계를 반복합니다.
`.clasp.json` 의 `scriptId` 만 원본 프로젝트의 것으로 바꾸면 됩니다.

금액이나 항목이 조금이라도 다르면 지우지 않으니, 같은 항목이 한 달에 두 번 있는 정당한 경우는 안전합니다.

프린터 5·6·7월에 각각 1원·2원·3원, 퇴직금 1,000만원.
**자동으로 지우지 않습니다.** `원장 점검` 리포트에 올리니 직접 판단해주세요.

**3. 보호자 연락처가 재원 68명 중 25명 공란입니다.**
성인반 7명을 빼면 미성년 18명입니다. 이 학생들은 알림이 나가지 않습니다.

**4. `보호자 성함` 은 전원 공란입니다.** 그래서 메시지 문구에 넣지 않습니다.

## 명단 3종을 다루는 규칙

학원의 실제 운영 방식에 맞춰 이렇게 판정합니다.

| 시트 | 성격 | 수강생명단과의 관계 |
|---|---|---|
| **퇴소생명단** | **이동** — 수강생명단에서 행을 빼서 옮김 | 동시 존재 시 **경고** |

**오늘이 휴원 구간 안에 드는가**로 판정합니다.

- 휴원종료일이 비어 있으면 → 아직 복귀 전이므로 **휴원**

출석부에서는 **휴원 구간이 그 달을 통째로 덮을 때만** 제외합니다.
월 중간에 휴원했다면 일부라도 다녔으므로 그 달에는 나옵니다.

> 예: `박영수` 은 수강생명단과 휴원생명단에 모두 있습니다. **이건 정상입니다.**
> 휴원시작일이 2026-07-01 이고 종료일이 비어 있어 현재 휴원 중으로 판정되고,
> 7·8월 출석부에서는 빠지지만 6월에는 나옵니다. 어느 행도 지우실 필요 없습니다.

## 관리자 모드 — 지난 날짜 소급 기록

태블릿이 고장 나 며칠치를 몰아 넣어야 할 때가 있습니다.
평소에는 **120분** 까지만 소급할 수 있지만, 관리자 모드에서는 제한이 풀립니다.

1. 앱 상단 가운데 **⚙️** 를 누릅니다
2. 관리자 PIN 을 입력합니다 → **30분간** 관리자 모드가 유지됩니다
3. 학생을 누르면 바텀시트에 **날짜·시각 직접 입력** 영역이 나타납니다
   - `오늘` `어제` 같은 빠른 선택 버튼과 날짜·시각 입력칸을 함께 제공합니다
   - ◀▶ 5분 버튼도 그대로 쓸 수 있습니다
4. 상단 배지에 남은 시간이 표시되고, ⚙️ 를 다시 누르면 즉시 해제됩니다

### 관리자로 기록하면 알림은 나가지 않습니다

월요일에 금요일 출결을 넣으면서 보호자에게 **사흘 지난 알림**이 가면 곤란합니다.
그래서 **관리자 모드에서는 알림이 기본으로 꺼져 있습니다.**

| 어떻게 기록했나 | 기본값 |
|---|---|
| 평소 (태블릿에서 학생·직원이 누름) | 켬 |
| **관리자 모드 (⚙ 로 잠금 해제)** | **끔** — 오늘 것이라도 |
| 관리자 화면의 [＋ 기록 추가] | **끔** |
| 관리자 화면의 [시각 수정] 정정 알림 | **끔** |

관리자 모드는 빠뜨린 것을 몰아 넣는 자리입니다. 켜져 있으면 한 건씩 끄면서 넣어야 해서
오히려 방해가 됩니다. **보내야 할 그 건만** 토글을 눌러 켜세요.

끈 채로 기록하면 로그의 발송상태가 `미발송(관리자)` 로 남고 비고에 `알림 미발송` 이
적힙니다. 발송 큐가 이 건을 집어가지 않습니다.

> 토글은 학생을 새로 고를 때마다 다시 꺼짐으로 돌아갑니다.
> 한 건 켜고 넣었다고 다음 건까지 켜져 있지는 않습니다.

> 이 판정도 **서버에서 합니다.** 관리자 티켓이 없으면 `notify` 값을 보내도 무시되고
> 평소 규칙대로 발송됩니다.

> **미래 시각은 관리자라도 기록할 수 없습니다.**
> 소급 기록은 로그 비고에 `관리자 소급 기록 (2026-08-21)` 로 남고,
> `입력시각` 에는 실제로 누른 시각이 그대로 남아 감사 추적이 됩니다.

제한 해제는 **서버가 발급한 시한부 티켓**으로 검증합니다.
클라이언트만 고쳐서는 뚫리지 않고, 티켓은 발급받은 그 기기에서만 씁니다.

## 관리자 화면

### 태블릿에서 바로 들어가기 (권장)

주소를 외울 필요가 없습니다.

```
출결 앱 상단의 ⚙ → 관리자 PIN 입력 → [관리자 화면 열기]
```

관리자 화면이 **새 탭**에서 열리고, 방금 PIN 을 넣었으므로 **다시 묻지 않습니다.**
상단에 남은 시간이 표시되고, 30분이 지나면 그 탭은 잠깁니다.

⚙ 를 다시 누르면 관리자 모드가 켜져 있는 동안에는 이 패널이 뜹니다.

| 버튼 | 하는 일 |
|---|---|
| 관리자 화면 열기 | 새 탭에서 관리자 화면을 연다 |
| 관리자 모드 해제 | 티켓을 즉시 버린다. 소급 기록 제한도 되돌아온다 |

> 태블릿 브라우저가 새 탭을 막으면 주소와 **복사 버튼**이 대신 나타납니다.

### 주소로 직접 들어가기

**출결 관리 → 관리자 화면 열기** 를 누르면 주소가 나옵니다.
출결 앱 주소 뒤에 `?page=admin` 을 붙인 것이라, 메뉴를 쓰지 않고 직접 쳐도 됩니다.

```
https://script.google.com/macros/s/.../exec?page=admin
```

이 경로로 들어가면 **관리자 PIN 을 한 번 더** 입력합니다.
어느 쪽이든 기기 등록이 된 태블릿·PC 여야 합니다.

> 메뉴가 `/dev` 로 끝나는 주소를 보여준다면 배포 주소가 등록되지 않은 것입니다.
> **7단계** 를 참고해 [웹앱 주소 등록] 을 먼저 해주세요.

### 같은 학생을 다시 누르면 고쳐집니다

시각을 잘못 찍었을 때 그 학생을 다시 눌러 시각을 맞추고 같은 버튼을 누르면 됩니다.

```
이미 19:23에 하원 기록이 있습니다. 19:28 로 고칠까요?
```

확인을 누르면 **새 줄이 생기지 않고 그 기록이 고쳐집니다.** 관리자 화면 목록에도
한 줄만 남고 `수정됨` 표가 붙습니다. 무엇이 무엇으로 바뀌었는지는
`_출결_이력` 에 `재기록` 으로 남습니다.

| | |
|---|---|
| 판정 범위 | `중복차단분`(기본 10분) 안. 그보다 벌어지면 별개의 기록으로 봅니다 |
| 과목 | 복수 과목 학생은 **같은 과목**일 때만 고칩니다. 피아노와 작곡은 서로 별개입니다 |
| 출석부 O | 같은 날 안에서 시각만 바뀌면 그대로 둡니다 |
| 알림 | 아직 안 나갔으면 고친 시각으로 나갑니다. **이미 나갔으면 다시 보내지 않습니다** |

> 취소된 기록은 되살리지 않고, 다른 학생·다른 구분의 기록도 건드리지 않습니다.
> 조건이 어긋나면 예전처럼 새 줄로 남습니다 — 엉뚱한 기록을 덮어쓰는 것보다 낫습니다.

> 오프라인 대기열에 쌓였다 올라가는 기록은 덮어쓰지 않고 그대로 쌓입니다.

### 고칠 기록을 이름으로 찾기

기록이 쌓인 날은 눈으로 훑기 어렵고, **언제 잘못 찍혔는지 모르면** 날짜를 하나씩
넘겨가며 뒤져야 했습니다. 날짜 줄 아래 검색칸에 이름이나 초성을 넣으세요.

| 범위 | 하는 일 |
|---|---|
| **이 날짜** | 보고 있는 날짜 안에서만 거릅니다. 서버를 다시 부르지 않습니다 |
| **최근 60일** | 날짜를 넘어 찾습니다. 행마다 날짜가 함께 표시되고, 눌러서 바로 고칠 수 있습니다 |

최근 것부터 보여줍니다. 방금 잘못 찍은 걸 고치러 오는 경우가 대부분이라서입니다.
취소된 기록도 함께 나옵니다.

> 다른 날 기록을 고쳐도 **그 기록이 속한 날짜**로 수정됩니다.
> 화면이 보고 있던 날짜로 끌려가지 않습니다.

### 하루치 목록에서 이름으로 찾기

기록이 쌓인 날은 눈으로 훑기 어렵습니다. 날짜 줄 아래 검색칸에 이름이나 초성을 넣으면
그 자리에서 걸러집니다. 이미 받아 둔 목록에서 거르므로 서버를 다시 부르지 않습니다.

```
홍길동   →  홍길동
ㅎㄱㄷ   →  홍길동
ㄱㅎ     →  김하늘
```

**자음만 쳤을 때에만 초성으로 봅니다.** 완성된 글자까지 초성으로 대조하면
`홍` 이 `김하늘`(ㄱ**ㅎ**ㄴ) 을 잡아버립니다.

### 티켓은 그 기기의 것입니다

⚙ 로 발급되는 관리자 티켓은 **발급받은 기기에서만** 통합니다.
주소에 실린 티켓을 다른 기기로 옮겨도 서버가 기기 토큰과 대조해 막습니다.
유효 시간도 30분이라, 현관 태블릿이 관리자 상태로 방치되지 않습니다.

### 할 수 있는 것

| 작업 | 설명 |
|---|---|
| **시각 수정** | 날짜까지 바꿀 수 있습니다. 날짜가 바뀌면 **출석부의 O 도 함께 옮깁니다** |
| **구분 변경** | 등원↔하원. 등원→하원이면 O 를 거두고, 반대면 O 를 찍습니다 |
| **기록 취소** | 행을 지우지 않고 상태만 `취소됨` 으로 바꿉니다 |
| **재발송** | 실패한 알림을 다시 대기로 돌립니다 |
| **기록 추가** | 누락분을 손으로 넣습니다. 학생 검색·과목 선택·알림 여부를 고를 수 있습니다 |

**모든 변경에 사유가 필수**이고 `_출결_이력` 에 이전값·이후값과 함께 남습니다.
화면 아래 `최근 변경 이력` 에서 바로 확인할 수 있습니다.

### 두 가지 안전장치

**기록을 물리적으로 지우지 않습니다.** 취소는 상태만 바꿉니다. 지워버리면
왜 사라졌는지 알 수 없기 때문입니다. 목록에도 취소선이 그어진 채로 남습니다.

**같은 날 다른 등원이 남아 있으면 O 를 유지합니다.** 중복 기록 하나를 지웠다고
출석 자체가 사라지면 안 되니까요. 마지막 하나를 취소할 때만 O 가 해제됩니다.

## 태블릿 앱에서 알아둘 것

### 휴원생도 명부에 나옵니다

복귀 첫날처럼 갑자기 오는 경우가 있어 **휴원생도 기록할 수 있게** 열어두었습니다.
카드에 `휴원 중` 배지가 붙고 테두리가 점선으로 표시됩니다.

> 휴원생은 그달 출석부에 행이 없을 수 있습니다. 그러면 기록은 남되
> "원장에 행이 없습니다" 안내가 뜹니다. 복귀가 확정되면
> 휴원생명단의 **휴원종료일** 을 채우고 **명부 동기화 → 출석부 재생성** 을 해주세요.

**퇴소생은 명부에 나오지 않고 기록도 막힙니다.**

### 오늘 누가 왔고 누가 아직 안 갔나

과목 칩 위에 보기 탭이 있습니다. **직원 모드에서만** 보입니다.

| 탭 | 보이는 것 |
|---|---|
| **명부** | 전체 명부 (가나다순) |
| **출석 12** | 오늘 등원한 학생. 하원까지 마친 학생도 포함됩니다 |
| **하원 5** | **아직 하원하지 않은** 학생. 하원 처리가 남았다는 뜻입니다 |

출석·하원 탭은 **온 순서**로 늘어놓습니다. 먼저 온 학생이 위에 있어야
오래 남아 있는 학생이 눈에 띕니다. 명부 탭은 그대로 가나다순입니다.

과목 칩·이름 검색과 겹쳐 쓸 수 있습니다 — `하원` + `작곡` 이면
아직 안 간 작곡 수강생만 나옵니다.

> 등원 기록 없이 하원만 있는 학생은 어느 쪽에도 잡히지 않습니다.
> 오지도 않았는데 하원 대기로 뜨면 목록만 지저분해집니다.

### 키오스크 모드에서는 인원 수를 숨깁니다

학생이 현관에서 보는 화면에 학원 규모가 드러날 이유가 없어,
하단의 `명부 68명 · 등원 12명` 표시를 **키오스크 모드에서만** 감춥니다.
직원 모드에서는 그대로 보입니다.

같은 이유로 위의 **보기 탭도 키오스크에서는 나오지 않습니다.** 건수가 그대로
드러나고, 현관에서 학생이 볼 화면도 아닙니다.

### 복수 과목 학생은 수업을 고릅니다

`피아노+작곡` 처럼 과목이 둘 이상인 학생은 바텀시트에 **수업 선택 칩**이 나타납니다.
**여러 개 고를 수 있고** 기본은 전부 선택입니다.

```
어떤 수업인가요?  여러 개 고를 수 있습니다
[ ✓ 피아노 ]  [ ✓ 작곡 ]
```

고른 수업의 출석부 행에만 O 가 찍힙니다. 피아노만 온 날은 피아노 행에만 표시됩니다.
로그의 `과목` 열에도 무엇을 골랐는지 남습니다.

**알림은 몇 개를 고르든 1건만** 나갑니다. 그리고 **과목이 다르면 중복으로 보지 않습니다** —
피아노 등원 직후 작곡 등원을 눌러도 막히지 않습니다.

### 학원 로고 넣기 (선택)

로고를 넣으면 상단바에 작은 마크가, 기기 등록·관리자 잠금 화면에 큰 로고가,
배경에는 아주 옅은 워터마크가 깔립니다.

```bash
npm run brand -- "C:/경로/학원로고.png"
npm run push
```

png · jpg · gif · webp · svg 를 받습니다. 이미지를 코드 안에 직접 심기 때문에
**가로 600px 정도로 줄여서 넣는 것을 권합니다.** 250KB 를 넘으면 경고가 뜹니다.

배경 워터마크가 너무 옅거나 진하면 진하기를 바꿀 수 있습니다 (기본 `0.25`).

```bash
npm run brand -- "C:/경로/학원로고.png" --opacity 0.4   # 더 진하게
npm run brand -- "C:/경로/학원로고.png" --opacity 0.1   # 더 옅게
```

```bash
npm run brand              # 지금 로고가 들어가 있는지 확인
npm run brand -- --remove  # 로고를 걷어냄
```

> **로고 파일은 저장소에 올라가지 않습니다.** 상표 이미지라 `src/Brand.html` 을
> `.gitignore` 에 넣어두었습니다. clasp 은 그대로 올리므로 화면에는 반영됩니다.
> 저장소를 다른 PC 에 내려받으면 로고가 없는 상태이고, **로고 없이도 앱은 그대로 돕니다** —
> 브랜드 스타일이 이 파일 하나에만 있어서 파일이 없으면 규칙이 통째로 빠질 뿐입니다.

## 발송 준비 (사람이 해야 하는 일)

개발과 병행해 지금 시작하셔야 합니다.

1. **발송 대행사 선택** — 솔라피 또는 알리고. 어댑터 구조라 나중에 바꿔도 됩니다
2. **발신번호 사전등록** — 통신서비스 이용증명원 발급 → 대행사 콘솔 등록 (무료, 1~2일)
   전기통신사업법 제84조의2에 따른 **법적 의무**이며, 없으면 발송 자체가 막힙니다
3. **카카오 비즈니스 채널에 발신프로필 등록**
4. **알림톡 템플릿 심사 접수** — **한 벌만** 내면 됩니다 (영업일 2~5일)

등원과 하원을 `#{구분}` 하나로 갈아 끼웁니다. 템플릿을 두 벌 만들면 심사도 두 번이고,
나중에 문구를 고칠 때 한쪽만 고쳐 놓기 십상입니다.

```
[어썸음악학원🎶]

#{날짜} #{학생명} 학생이 #{시간}에 #{등하원조건}하였습니다.#{이모티콘}
```

| 변수 | 들어가는 값 |
|---|---|
| `#{학원명}` | 기본정보 시트의 학원명 |
| `#{날짜}` | `26.08.05` |
| `#{학생명}` | 표시명 (동명이인이면 접미사 포함) |
| `#{시간}` | `22:25` |
| **`#{등하원조건}`** | 등원이면 `출석`, 하원이면 `하원` |
| **`#{이모티콘}`** | 등원이면 `✨`, 하원이면 `🍀` |

> 심사에는 **위 문구 그대로** 올리세요. 학원명(`어썸음악학원`)과 머리말의 `🎶` 는
> 고정 문구로 두고 나머지를 변수로 지정하면 됩니다.

두 값 모두 **알림톡 변수값**이라 바꿔도 재심사가 필요 없습니다.
`Config.gs` 의 `KIND_WORD` / `KIND_EMOJI` 한 줄이면 됩니다.

#### 수신거부 버튼

템플릿에 **웹링크 버튼**을 하나 답니다. **버튼도 심사 대상이라 지금 같이 올려야 합니다.**

| | |
|---|---|
| 버튼명 | 출결 알림 받지 않기 |
| 링크 | `…/exec?page=optout&k=#{수신거부키}` |

`#{수신거부키}` 는 학생마다 다른 **서명된 값**입니다. 학생ID 만 실으면 `S002` 로
고쳐 남의 알림을 끌 수 있어서 HMAC 서명을 붙였습니다.

> **대행사 콘솔이 링크에 변수를 안 받아줄 수 있습니다.** 그때는 변수 없이
> `…/exec?page=optout` 만 등록하세요. 화면이 **학생 이름과 보호자 연락처**를 물어
> 본인을 확인합니다(둘 다 맞아야 열립니다). 어느 쪽이든 코드는 그대로입니다.
>
> 정확한 링크 두 벌은 **[발송 설정 점검]** 이 그대로 찍어줍니다.

**심사 전에 화면을 확인하시려면** 메뉴 **[출결 관리] → 발송 → 수신거부 링크 만들기**
에서 학생 한 명의 실제 링크를 뽑을 수 있습니다. `#{수신거부키}` 가 채워진 주소라
휴대폰에서 열면 보호자가 보는 화면이 그대로 나옵니다.
보호자가 "링크를 못 받았다" 할 때 만들어 전달하는 용도로도 씁니다.

보호자가 버튼을 누르면 휴대폰에서 이 화면이 열립니다.

```
        홍길동 학생
  지금은 출결 알림을 받고 있습니다.

  ┌────────────────────────┐
  │  출결 알림 받지 않기      │
  └────────────────────────┘
```

끄면 `_출결_학생` 의 `알림수신` 이 꺼지고 `_출결_이력` 에 남습니다.
**같은 화면에서 언제든 다시 켤 수 있습니다** — 안 그러면 학원에 전화해야 합니다.

#### ⚠ 채널 차단은 해결이 아닙니다

보호자가 카카오 채널을 **차단**하면 알림톡이 실패하고, `SMS폴백사용` 에 따라
**문자로 나갑니다.** 차단할수록 더 끈질기게 가는 셈입니다.
그래서 수신거부는 반드시 위 버튼으로 `알림수신` 을 꺼야 합니다.

#### 봇 키워드로는 안 됩니다

카카오 채널의 봇 키워드를 눌러도 우리 시스템은 아무것도 받지 못합니다.
스킬 서버를 붙여도 카카오가 넘겨주는 건 **채널 전용 익명 ID** 라, 그 사람이
어느 학생의 보호자인지 알 방법이 없습니다. 봇에는 안내만 두세요.

> "출결 알림 수신 거부는 받으신 알림 메시지 하단의 **[출결 알림 받지 않기]** 버튼을 눌러주세요."

**이모지는 알림톡에만 나갑니다.** 국내 SMS/LMS 는 EUC-KR 기준이라 `🎶` `✨` `🍀` 를
표현할 수 없어서, SMS 로 대체될 때는 코드가 자동으로 걷어냅니다.

```
등원  알림톡  [어썸음악학원🎶] ⏎⏎ 26.08.05 홍길동 학생이 22:25에 출석하였습니다.✨
      SMS     [어썸음악학원]   ⏎⏎ 26.08.05 홍길동 학생이 22:25에 출석하였습니다.     62바이트

하원  알림톡  [어썸음악학원🎶] ⏎⏎ 26.08.05 홍길동 학생이 22:25에 하원하였습니다.🍀
      SMS     [어썸음악학원]   ⏎⏎ 26.08.05 홍길동 학생이 22:25에 하원하였습니다.     62바이트
```

> 문구를 두 벌 두지 않고 발송 직전에 걷어내는 이유는, 두 벌이면 한쪽만 고쳐 놓고
> 반드시 어긋나기 때문입니다.
>
> SMS 90바이트를 넘으면 LMS 로 넘어가 단가가 3배입니다. 위 문구는 62바이트라
> 4자 이름(64바이트)까지도 여유가 있습니다.

### 설정은 어디서 고치나

**출결 관리 → 발송 → 발송 설정 열기** 를 누르면 `_출결_설정` 시트로 이동합니다.
**B열의 값만 고치면 됩니다.**

| 키 | 값 |
|---|---|
| `공급사` | `test` / `solapi` / `aligo` |
| `발신번호` | 사전등록한 학원 대표번호 |
| **`문구`** | ⚠ 알림톡 사용 중에는 수정 금지 (아래 참조). 등·하원 공용입니다 |
| `발신프로필키` | 알림톡 발신프로필 키 (비우면 SMS 로만 발송) |
| `템플릿ID` | 심사 통과한 알림톡 템플릿 코드. 한 벌만 쓰므로 하나입니다 |
| `SMS폴백사용` | `TRUE` / `FALSE` |
| `중복차단분` / `소급최대분` | 기본 10 / 120 |

문구에 쓸 수 있는 변수는 여섯 개입니다.

```
#{학원명}  #{학생명}  #{날짜}  #{시간}  #{등하원조건}  #{이모티콘}  #{수신거부키}
```

`#{수신거부키}` 는 본문이 아니라 **버튼 링크**에 씁니다.

다른 변수를 쓰면 글자 그대로 발송되며, 점검 화면이 경고합니다.
`#{등하원조건}` 을 빼면 등원과 하원 알림이 똑같이 나가므로 점검 화면이 잡아냅니다.

> 예전 이름 `#{일자}` `#{시각}` `#{구분}` 도 그대로 동작합니다.
> 이미 시트에 적어둔 문구가 조용히 깨지지 않게 하기 위함입니다.

> **API 키·시크릿은 이 시트에 두지 않습니다.** Script Properties 에 따로 저장합니다.
> 스프레드시트를 누군가와 공유해도 키가 새지 않게 하기 위함입니다.

> **`_출결_기기` 시트는 숨겨져 있습니다.** 접속 토큰이 들어 있어서,
> 그 값을 아는 사람은 해당 태블릿과 같은 권한을 갖습니다.

고친 뒤 **발송 설정 점검** 을 누르면 **실제로 나갈 문구와 바이트 수**를 보여줍니다.
설정 변경은 시트를 편집하는 즉시 반영됩니다.

### 문구는 언제 고쳐도 되나

`문구` 는 **상황에 따라** 다릅니다. 그래서 무조건 막지 않고,
편집하려 하면 **확인 창이 뜨도록** 경고형 보호를 걸어두었습니다.

| 상황 | 수정 |
|---|---|
| **알림톡 사용 중** | **금지** — 심사 통과한 템플릿과 한 글자라도 다르면 발송이 거부됩니다 |
| SMS 만 쓰는 동안 (심사 전) | 자유 |
| 알림톡 템플릿을 **새로 심사받았을 때** | **반드시 수정** — 새 템플릿 문구와 똑같이 맞춰야 합니다 |

알림톡이 켜져 있으면 **발송 설정 점검** 이 이 경고를 함께 보여줍니다.
SMS 폴백으로 나가는 문구는 언제든 자유롭게 바꿔도 됩니다.

> 설정 항목이 시트에 없다면 **발송 설정 열기** 를 한 번 누르세요.
> 나중에 추가된 항목을 자동으로 채워 넣습니다. 설치를 다시 할 필요는 없습니다.

### 계정이 없어도 지금 점검할 수 있습니다

`_출결_설정` 시트의 **공급사** 가 비어 있거나 `test` 면 **테스트 모드**로 돕니다.
실제로 발송하지 않고 로그만 남기므로, 대행사 가입 전에도 전 구간을 확인할 수 있습니다.

**출결 관리 → 발송 → 발송 설정 점검** 을 누르면 지금 상태와
실제로 나갈 문구·바이트 수를 보여줍니다.

### 계정이 준비되면

1. Apps Script 편집기에서 인증정보를 넣습니다 (시트가 아니라 Script Properties 에 저장됩니다)

```javascript
setProviderSecrets('solapi', 'API키', 'API시크릿')
setProviderSecrets('aligo',  'API키', '사용자ID')
```

2. `_출결_설정` 시트를 채웁니다

| 키 | 값 |
|---|---|
| 공급사 | `solapi` 또는 `aligo` |
| 발신번호 | 사전등록한 학원 대표번호 |
| 발신프로필키 | 알림톡 발신프로필 키 (없으면 SMS 로만 발송) |
| 템플릿ID | 심사 통과한 템플릿 코드 (한 벌) |

3. **발송 설정 점검** 으로 확인 → **지금 발송 처리** 로 1건 실발송

> **알림톡 심사 전에는 발신프로필키·템플릿ID 를 비워두세요.**
> 그러면 SMS 로만 나가고, 심사가 끝난 뒤 이 세 칸만 채우면 알림톡으로 전환됩니다.
> **코드는 건드리지 않습니다.**

발송에 실패한 건은 지수적으로 3회까지 자동 재시도하고, 그래도 안 되면 `실패` 로 확정합니다.
**발송 → 실패 건 재시도** 로 다시 시도할 수 있습니다.

예상 비용: 68명 × 2건 × 월 20일 ≈ 2,720건 → **알림톡 기준 월 약 2만원**

## 주소 하나를 나눠 쓰는 문제

출결 앱·관리자 화면·보호자 수신거부가 **같은 웹앱 주소**를 씁니다. `?page=` 만 다릅니다.

```
…/exec                        출결 앱      기기 토큰 필요
…/exec?page=admin             관리자 화면   기기 토큰 + 관리자 PIN
…/exec?page=optout&k=…        수신거부     서명된 학생 키
```

수신거부 버튼을 달면 **그 주소가 보호자 휴대폰마다 들어갑니다.** 뒤를 잘라내고
들어오는 사람이 생긴다고 보고 막아두었습니다.

| 막는 것 | 어떻게 |
|---|---|
| 기기 등록 화면 노출 | 시한부 등록 링크(30분)로 들어온 경우에만 뜹니다. 그 밖에는 **PIN 입력창 자체가 없습니다** |
| 화면을 건너뛴 직접 호출 | `registerDevice` 가 서버에서 등록 링크를 다시 검증합니다 |
| PIN 무차별 대입 | 5번 틀리면 10분 잠깁니다. 등록용과 관리자용을 따로 셉니다 |
| 명부 유출 | 토큰이 없으면 `getBootstrap` 이 명부를 아예 내려주지 않습니다 |

> **PIN 만으로는 부족합니다.** 시도 제한이 없으면 네 자리 PIN 은 브라우저
> 콘솔로 몇 분이면 뚫립니다. 입구를 없애는 것과 횟수를 제한하는 것, 둘 다 필요합니다.

> 등록 링크를 만들 수 있는 사람은 **스프레드시트 편집 권한이 있는 사람**뿐입니다.
> 구글 로그인이 이미 그 문을 지키고 있습니다.

더 세게 나누고 싶으면 수신거부 화면만 **별도 Apps Script 프로젝트**로 떼어
같은 스프레드시트를 열게 할 수 있습니다. 보호자가 출결 시스템 주소를 아예
보지 못하게 되지만, 배포와 관리가 두 벌이 됩니다.

## 시트 구성

### 앱이 새로 만드는 시트

| 시트 | 역할 |
|---|---|
| `_출결_학생` | 학생 마스터. **행을 절대 삭제하지 않습니다** (동명이인 접미사 대장을 겸함) |
| `_출결_로그` | 시각 단위 출결 원장. `입력시각`과 `출결시각`을 분리해 감사 추적 |
| `_출결_기기` | 태블릿 등록 (숨김 — 접속 토큰이 들어 있음) |
| `_출결_설정` | 공급사·발신번호·**문구**·템플릿ID. **API 키는 여기 두지 않습니다** |
| `_출결_이력` | 관리자 수정 감사 로그 |
| `_지출_입력` | 연도별 지출 입력 격자 |

### 기존 시트와의 관계

| 시트 | 앱의 동작 |
|---|---|
| 수강생명단 | **읽기 전용.** 예외로 보호자 연락처(I열)만 앱에서 입력 가능 |
| 휴원생명단 / 퇴소생명단 | 읽기 전용. 상태·월별 재적 판정에 사용 |
| **출석부(DB)** (숨김) | **출결 원장.** 재생성이 건드리지 않습니다 |
| **출석부** | 선택된 연/월의 **뷰.** 언제든 원장에서 다시 그립니다 |
| **지출(DB)** (숨김) | 지출 격자가 upsert |
| 대시보드 · 수강료 · 수입/지출 | **건드리지 않습니다** |

## 알아두면 좋은 설계

**출석부는 뷰, `출석부(DB)`가 원장입니다.**
등원을 기록하면 원장에 먼저 쓰고, 출석부가 마침 그 달을 보고 있을 때만 화면에도 찍습니다.
지난달 출석부를 인쇄하려고 월을 바꿔둔 상태에서 등원해도 원장에는 정확히 남고,
그 달로 돌아오면 복원됩니다.

**동명이인 접미사는 재사용하지 않습니다.**
첫 학생은 무표기, 중복이 생기면 `A`, `B`, `C`. `홍길동A` 가 퇴소해도
다음 학생은 `A` 를 물려받지 않고 `C` 를 받습니다. 그래야 표시명이 시점과 무관하게
한 사람만 가리키고, 출결 이력이 다른 학생에게 옮겨붙지 않습니다.
이 때문에 `_출결_학생` 시트는 행을 지우지 않고 상태만 바꿉니다.

**과목은 `+` 로 나눠 행을 복제합니다.**
`피아노+작곡` 인 김철수·이영희은 출석부에서 2행이 되고, 등원 1회에 두 행 모두 O가 찍히되
알림은 1건만 나갑니다. 기존의 `김철수 P` / `김철수 C` 표기는 과목명 열로 옮겨졌습니다.

**단일 과목은 원문을 그대로 씁니다.** `피아노(초등부)` 처럼 학년부 정보를 잃지 않습니다.

## 개발

```
src/
  Config.gs      시트명·좌표 상수, 설정 로더
  Util.gs        시각·바이트·전화번호·초성·접미사 (순수 함수)
  Repo.gs        시트 CRUD 계층
  Setup.gs       설치, 좌표 실측(probeLayout)
  Sync.gs        명부 동기화, 상태 판정, 동명이인 접미사 발급
  Attendbook.gs  출석부 동적 생성, O 기입/해제
  Expense.gs     지출 원장 정리, 연도별 격자
  Auth.gs        기기 토큰, 관리자 PIN·티켓

  ProviderSolapi.gs / ProviderAligo.gs   대행사별 구현
  Triggers.gs    자동 실행 (발송 큐 · 명부 동기화 · 월 롤오버)
  AdminApi.gs    관리자 화면 서버 로직 (수정·취소·재발송·수동 추가)
```

> **파일 이름은 확장자를 뺀 상태로 유일해야 합니다.**
> Apps Script 는 `Admin.gs` 와 `Admin.html` 을 같은 이름으로 보고 push 를 거부합니다
> (`A file with this name already exists`). 그래서 서버 파일은 `AdminApi.gs` 입니다.

좌표는 코드에 박지 않고 `probeLayout()` 이 **헤더 텍스트를 찾아 실측**합니다.
템플릿 버전이 달라 행이 밀려도 조용히 엉뚱한 칸을 건드리지 않게 하기 위함입니다.

```bash
npm run push            # 이름 검사 후 업로드
npm run brand -- <파일>  # 학원 로고 심기
npx clasp logs --watch  # 실행 로그
```

### 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| `User has not enabled the Apps Script API` | 4단계 — 설정에서 API 켜기 |
| `[출결 관리]` 메뉴가 안 보임 | 스프레드시트 새로고침(F5). `clasp push` 가 끝났는지 확인 |
| `시트를 찾을 수 없습니다: "..."` | `설치·설정 → 좌표 다시 실측` 실행. 리포트 첫 줄에 이 파일의 **모든 탭 이름**이 나오니 그걸로 어느 시트가 없는지 확인하세요 |
| `Cannot call SpreadsheetApp.getActive()` | 독립 프로젝트로 만든 경우. 1단계로 돌아가 시트 메뉴에서 다시 생성 |
| 권한 승인 창에서 "안전하지 않은 페이지" 경고 | 본인이 만든 스크립트라 정상입니다. **고급 → (프로젝트명)(으)로 이동 → 허용** |

### 시트 이름이 달라도 됩니다

앱은 탭 **이름을 추측하지 않습니다.** 헤더 구조로 역할을 판별합니다.

| 역할 | 찾는 헤더 |
|---|---|
| 수강생명단 | `이름` `과목` `보호자 연락처` `등록일` (휴원시작일·퇴소일이 **없는** 시트) |
| 휴원생명단 | 위 + `휴원시작일` |
| 퇴소생명단 | 위 + `퇴소일` |
| 출석부 | `번호` `이름` `과목명` `수강요일` |
| 출결 원장 | `연도` `수강월` `번호` `이름` `과목명` |
| 지출 원장 | `연도` `월` `예산구분` `사업항목` `금액` |

탭 이름이 `출석부 데이터` 든 `DB_지출` 이든 헤더만 맞으면 찾아냅니다.

> **이 학원의 실제 이름**: 출결 원장은 `출석부(DB)`, 지출 원장은 `지출(DB)` 이며
> **둘 다 숨김 시트**라 탭 목록에 보이지 않습니다. 설명서에도 언급이 없습니다.
> 숨김이어도 앱은 정상적으로 읽고 씁니다.
`좌표 다시 실측` 리포트에 **"시트 확정: A → B (헤더 구조로 찾음)"** 으로 표시되니
엉뚱한 시트를 잡지 않았는지 한 번 확인해주세요.

**출결 원장이 아예 없으면** `최초 설치` 가 `출석부(누적)` 시트를 같은 구조로 만들어 줍니다.
이 경우 과거 출결 기록은 없는 상태에서 시작합니다.
**지출 원장이 없으면** 지출 기능만 쓸 수 없고 출결은 정상 동작합니다.
